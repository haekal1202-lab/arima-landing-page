LPKS ARIMA PERSADA — WEBSITE FINAL

Isi paket:
- index.html: halaman utama untuk deployment Vercel.
- assets/: logo resmi dan foto dokumentasi asli yang telah dioptimalkan.

Cara pasang:
1. Ekstrak ZIP ini.
2. Unggah/commit index.html dan folder assets/ ke root proyek Vercel bersama file proyek lain yang memang masih digunakan.
3. Jika mengganti website lama, simpan cadangan file index.html sebelumnya.
4. Deploy ulang dan uji tombol TEMUKAN JALURMU, alur kuis, serta WhatsApp.

Versi HTML satu file tersedia terpisah jika dibutuhkan; versi itu menanamkan gambar langsung ke dalam HTML.
